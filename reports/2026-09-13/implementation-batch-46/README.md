# الدفعة 46: استرجاع النسخ القديمة عبر ملف مرحلي

## السلوك المنفذ

- يقرأ الاسترجاع سلامة قاعدة النسخة وإصدار مخططها قبل لمس قاعدة المحل الحالية.
- يقبل الإصدارات المدعومة من v3 حتى v11، ويرفض إصدارًا أقدم أو أحدث برسالة واضحة.
- ينسخ الملف المختار إلى مجلد مرحلي ثم يشغّل سلسلة Drift للترحيل على النسخة المرحلية فقط.
- يفحص بعد الترحيل إصدار v11، وكل الجداول والأعمدة المتوقعة، و`quick_check`، و`foreign_key_check`.
- يبدأ إنشاء نسخة الرجوع وإغلاق قاعدة التشغيل بعد نجاح تجهيز الملف المرحلي فقط.
- تستخدم الحزمة المحمولة المسار نفسه قبل تثبيت الصور وتحديث مساراتها.

## اختبارات الانحدار

- استرجاع ملف v4 إلى v11 مع بقاء محتوى ملف النسخة الأصلي دون تغيير.
- فشل ترحيل ملف v4 ناقص مع بقاء قاعدة المحل مفتوحة ونجاح الدخول إليها.
- ترقية قاعدة v4 داخل حزمة محمولة واستعادة صورة الخلفية إلى مسار الجهاز الجديد.
- رفض النسخة الأحدث والجداول الناقصة والمراجع المكسورة قبل إغلاق قاعدة التشغيل ما زال مغطى باختبارات الاعتمادية.

## حدود الإثبات

الاختبارات تستخدم قواعد اصطناعية وملفات مؤقتة محلية. يلزم قبل الإصدار التجاري استرجاع نسخة منزوعة الهوية تمثل بيانات متجر قديمة من وسيط النسخ المستهدف على جهازي Windows وLinux، ثم مراجعة الأرصدة والتقارير وتوقيع نموذج القبول الميداني.
