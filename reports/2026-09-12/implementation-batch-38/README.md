# الدفعة 38: دورة حياة مُثبّتات سطح المكتب

## ما نُفذ

- أضيف فحص تشغيل مخفي `--installer-smoke-check` يفتح قاعدة التطبيق الحقيقية، يشغل `PRAGMA quick_check`، ويتأكد من مخطط البيانات 11 قبل الخروج برمز واضح.
- أضيف قبول آلي لحزمة Debian يثبت نسخة قديمة اصطناعية، يشغلها، يرقيها إلى النسخة الحالية، يزيلها، ثم يعيد تثبيتها، مع إثبات بقاء قاعدة البيانات وملف شاهد للمستخدم.
- أضيف المسار المناظر لمُثبّت Windows باستخدام NSIS وPowerShell.
