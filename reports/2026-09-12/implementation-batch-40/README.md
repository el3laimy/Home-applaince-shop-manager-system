# الدفعة 40: التعافي من امتلاء القرص

- أضيف اختبار SQLite ملفي يفرض `SQLITE_FULL` أثناء إنشاء منتج برصيد افتتاحي كبير.
- يثبت الاختبار رجوع المنتج وحركة المخزون والقيد وسطوره وإيصال منع التكرار معًا، وبقاء `PRAGMA quick_check = ok`.
- بعد استعادة مساحة الكتابة يعيد الطلب نفسه بنجاح، فلا تبقى حالة نصف محفوظة ولا يضطر المستخدم إلى تغيير مفتاح العملية.
- أصبحت أخطاء التخزين المعروفة تعرض رسالة عربية عملية وتبقي الطلب المالي المعلق لإعادة المحاولة. أخطاء SQLite الأخرى لا تُخفى تحت رسالة امتلاء عامة.

## التحقق

- commit محلي: `210a753`.
- نجح التحليل واختبار `disk_full_recovery_test.dart` واختبار شاشة الدعم بعد التغيير.

## الحدود المفتوحة

الاختبار يحاكي حد صفحات SQLite على ملف حقيقي. قطع الطاقة أو امتلاء قسم نظام التشغيل كاملًا على جهاز Windows/Linux فعليين يظلان اختباري قبول منفصلين.
