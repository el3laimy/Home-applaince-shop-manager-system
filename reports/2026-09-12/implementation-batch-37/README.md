# دفعة 37 — استيراد CSV آمن للمنتجات

## السلوك المنفذ

- يستطيع المستخدم حفظ قالب CSV عربي من شاشة المخزون ثم اختيار ملف UTF-8 لا يتجاوز 2 ميجابايت و2000 منتج.
- تعرض المعاينة الاسم والباركود والكمية وسعر البيع لكل صف سليم، وتعرض الأخطاء برقم الصف. أي خطأ أو باركود موجود أو مكرر يمنع زر الاعتماد، فلا يوجد حفظ جزئي مبهم.
- يدعم القارئ الحقول المقتبسة والفاصلة داخل النص وعلامات الاقتباس المهربة وCRLF والأرقام العربية والفارسية والإنجليزية.
- يرفض الرصيد الموجب بلا تكلفة موجبة، والقيم السالبة أو الزائدة، والعناوين أو عدد الأعمدة غير المطابق للقالب.
- يعتمد الاستيراد السليم المنتجات وأرصدة المخزون وحركاتها وقيودها المتزنة في معاملة واحدة. لكل طلب مفتاح وبصمة وإيصال دائم، ويمكن استعادته بعد فقد الرد دون تكرار.
- يفحص منتقي الملف الحجم قبل قراءة المحتوى إلى الذاكرة، ثم يفك UTF-8 بصيغة صارمة ويعرض رسالة مفهومة عند الملف غير الصالح.

## دليل التحقق المحلي

- `flutter analyze`: نظيف بلا ملاحظات.
- اختبارات CSV والاستعادة المالية المركزة: 10 حالات ناجحة.
- `flutter test --no-pub --reporter compact`: 192 اختبارًا ناجحًا.
- `flutter build linux --release --no-pub --dart-define=APP_GIT_SHA=local-check`: نجح وأنتج `build/linux/x64/release/bundle/alikhlas_pos`.
- `git diff --check`: نظيف.

## حدود القبول

الاستيراد مخصص للمنتجات والمخزون الافتتاحي. أرصدة العملاء والموردين والخزينة والمحفظة لها شاشات منفصلة حتى يراجع المستخدم أثر كل رصيد. لا يثبت الاختبار المحلي سهولة نقل ملف حقيقي أنشئه مستخدم على Excel أو LibreOffice؛ يجب تجربته ضمن نقل دفاتر محل فعلي على Windows وLinux قبل قبول الإصدار ميدانيًا.
