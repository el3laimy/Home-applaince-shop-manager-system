# الدفعة 44: إصلاح إنشاء اختصار Windows

## العطل المثبت

في GitHub Actions run `34702270415` نجح بناء Windows وNSIS وفحص ملف المُثبّت وتشغيل التطبيق المثبت، ثم أبلغ اختبار القبول:

`Installer did not create required path: C:\Users\runneradmin\Desktop\إخلاص POS.lnk`

كان سكربت NSIS ينشئ الاختصار داخل `$DESKTOP` من دون ضمان وجود المجلد على Windows runner.

## الإصلاح

- ثُبت `SetShellVarContext current` صراحة لمساري التثبيت والإزالة.
- ينشئ المُثبّت `$DESKTOP` قبل `CreateShortcut`.
- بقي اختبار القبول يطلب الاختصار نفسه، حتى لا يتحول الإصلاح إلى تخفيف للشرط.

## القبول

لا يغلق هذا التغيير بوابة Windows وحده. يلزم نجاح run جديد في التثبيت والترقية والإزالة وإعادة التثبيت وبقاء بيانات المستخدم، ثم تجربة جهاز Windows نظيف قبل إعلان قبول ميداني.
