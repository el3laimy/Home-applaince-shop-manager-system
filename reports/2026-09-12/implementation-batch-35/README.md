# دفعة 35 — إغلاق ملاحظات المراجعة الفنية

## ما أُصلح في الكود

- أُغلق خلل WAC الكسري بإضافة أساس قيمة مخزون دقيق، وتخصيص تكلفة دقيقة للبيع ومرتجع البيع، ومطابقة مجموع قيم الأصناف مع حساب المخزون في الدفتر.
- لا يمكن تعطيل صنف له كمية أو قيمة مخزون، ويمكن إعادة تفعيله، ولا تختفي قيمته من شاشات المخزون والتقارير.
- الرصيد الافتتاحي الموجب يحتاج تكلفة موجبة، والشراء الجديد يرفض الصنف المعطل، وفتح أو إغلاق الوردية يرفض النقد السالب داخل طبقة الأعمال.
- ترقية v10 تنشئ الحقول الجديدة وتحتفظ بلقطة ما قبل التحديث. حالات علامة الترحيل أصبحت ملفات مستقلة غير قابلة للاستبدال، ينشر كل منها عبر ملف مؤقت و`flush` و`rename` بما يتوافق مع Windows.
- نجاح لقطة النسخ الاحتياطي لا يتحول إلى فشل عند تعذر حذف نسخة قديمة؛ يُحفظ وقت النجاح وتظهر رسالة تنظيف مستقلة.
- أصبح `bootstrap()` آمنًا افتراضيًا ولا ينشئ `owner123` إلا بطلب اختبار صريح. رُفعت PBKDF2-SHA256 إلى 600,000 تكرار، وأضيف حجب 15 دقيقة بعد خمس محاولات دخول خاطئة.
- أضيفت حواجز SQLite على القيم السالبة للمخزون والوردية، والكميات غير الموجبة في بنود المستندات، وأسطر الدفتر السالبة أو ثنائية الجانب.
- استُبدلت استخدامات `DateTime.now()` داخل Application Use Cases بالساعة المحقونة.
- الإصدار الآن `1.1.0+10` ومخطط البيانات `10`. يحقن CI رقم commit في شاشة المساعدة وتقرير الدعم.
- أزيلت `sqlite3_flutter_libs` المنتهية، وثُبتت GitHub Actions على commits محددة، ونُقل بناء NSIS إلى سكربت يتحقق من المدخلات والمخرج ويطبع تشخيصًا واضحًا.
- يمرر بناء NSIS ملف `app_icon.ico` الأصلي صراحة بدل محاولة قراءة الأيقونة من ملف التشغيل، مع التحقق من امتداده قبل التجميع.
- أزيلت 392 ملفًا من أدوات `.codex` من تتبع مستودع المنتج، وحُذف `dotnet-install.sh` و`test_wiki_scraper.cs` غير المستخدمين. تبقى أدوات `.codex` محليًا ومُستبعدة عبر `.gitignore`.

## ما يحتاج بيئة خارجية قبل الإنتاج

أثبت GitHub Actions بناء مُثبّت Windows ورفع artifact الناتج. تظل اختبارات التثبيت والترقية والإزالة على أجهزة نظيفة، والطابعة والماسح، وانقطاع الطاقة وامتلاء القرص، وتجربة مستخدم محل فعلية بوابات قبول ميدانية.

تشفير قاعدة البيانات على مستوى التطبيق لم يكن قرارًا مطلوبًا في الإصدار المحلي الحالي؛ سياسة هذا الإصدار هي حساب نظام تشغيل منفصل، وتشفير القرص حيث يتوفر، وحماية وجهة النسخ. إذا أصبح SQLCipher شرطًا تعاقديًا فيحتاج ترحيل بيانات وتوزيع مفاتيح ونموذج تهديد مستقلًا.

تقسيم الملفات الكبيرة تحسين صيانة غير وظيفي، وليس إصلاح سلامة بيانات. يُنفذ لاحقًا في تغييرات صغيرة بعد ثبات Release Candidate، مع إبقاء الاختبارات الحالية بوابة لكل نقل.
