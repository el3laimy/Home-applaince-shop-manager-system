# مصفوفة إغلاق تقرير المراجعة الفنية

هذه المصفوفة تفصل عيوب المصدر القابلة للإصلاح عن اختبارات القبول التي تحتاج جهازًا أو قرارًا تشغيليًا. لا تعني كلمة «مغلق» أن التطبيق أصبح جاهزًا للإنتاج ما لم تجتز بوابات القبول في القسم الأخير.

## ملاحظات التقرير خارج القائمة ذات الأولوية

- استخدام الساعة داخل حالات الاستخدام أصبح عبر الساعة المحقونة. بقي استخدام وقت النظام داخل كتابة اسم ملف علامة الترحيل، وهو أثر بنية ملفات لا حسابًا تجاريًا.
- يوجد مسار مساعدة وتقرير دعم منقح ودليل مرئي وتراخيص. أضيف سجل محلي منظم ومحدود الحجم للأخطاء غير المتوقعة، ولا يحفظ رسالة الاستثناء أو البيانات أو المسارات أو مفتاح العملية الخام؛ الدفعة 43.
- تشفير SQLite على مستوى التطبيق لم يعتمد ضمن نموذج الإصدار المحلي. السياسة الحالية تتطلب حساب نظام تشغيل منفصلًا وتشفير القرص وحماية وجهة النسخ؛ SQLCipher يحتاج قرار منتج وترحيل مفاتيح مستقلًا.

## بوابات القبول التي ما زالت مفتوحة

| البوابة | ما ثبت | ما يلزم لإغلاقها |
|---|---|---|
| Windows | نجح بناء bundle ومُثبّت Windows الأصلي على GitHub؛ واختبار NSIS المحلي أثبت قبول الوصفة والبنية فقط | رسالة الخطأ التفصيلية من Job الفاشل، run أخضر لدورة التثبيت/الترقية/الإزالة، ثم تجربة جهاز Windows نظيف |
| Linux | دورة حزمة Debian كاملة نجحت على GitHub runner | تجربة جهاز التسليم والتوزيعات المعتمدة |
| ترقية بيانات متجر | ترقيات مخططات اصطناعية ولقطة رجوع واختبارات اتساق | نسخة منزوعة الهوية تمثل قاعدة عميل قديمة أو نقل دفاتر فعلي تحت إشراف صاحب المحل |
| الطباعة والباركود | توليد الصفحات وحوار النظام واختبارات واجهة | طابعة إيصالات وملصقات وماسح فعليون على نظامي التسليم |
| النسخ الخارجي والاسترجاع | حزمة منقولة وبصمات وفحص واسترجاع بين مسارين | USB أو قرص خارجي فعلي، فصل الوسيط، وصلاحيات Windows/Linux |
| الأعطال | WAL و`FULL` ومنع تشغيل نسختين وفشل كتابة و`SQLITE_FULL` ذري | قتل عملية وقطع كهرباء وامتلاء قسم فعلي على جهاز اختبار |
| السعة | 10 آلاف صنف و50 ألف فاتورة، 193 اختبارًا، وصفر مشاكل اتساق | إعادة القياس على جهاز التسليم وبيانات ممثلة للمتجر |
| المستخدم النهائي | دليل عربي وإعداد أول وتشخيص واستعادة وصول | جلسة قبول مع مستخدم غير خبير وتسجيل الملاحظات والإصلاحات |
| التوقيع والدعم | الحزم تحمل الإصدار والـcommit والتراخيص | هوية ناشر Windows وشهادة توقيع وجهة دعم وساعات استجابة يحددها صاحب المنتج |

## قرار الحالة

عيوب P0/P1/P2 المحددة في مصدر التطبيق مغلقة، باستثناء أن دورة مُثبّت Windows الجديدة لم تجتز CI بعد. التطبيق صالح لمواصلة Pilot مضبوط، لكنه لا يوصف بأنه Production Ready إلى أن تُغلق بوابات الأجهزة والبيانات الواقعية والمستخدم والتوقيع أعلاه.
