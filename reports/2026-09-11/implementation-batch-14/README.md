# دفعة 14: حزمة نقل البيانات والصور

- ZIP يدوي يحتوي قاعدة البيانات والصور وفهرس SHA-256.
- الاسترجاع يتحقق من المحتوى والمسارات وحدود الحجم ويعيد ربط الصور بالجهاز الهدف.
- اختبار نقل بين مسارين مستقلين نجح.
- `dart analyze lib/v2 lib/main.dart test/v2`: بلا ملاحظات.
- `flutter test --no-pub`: 114 اختبارًا ناجحًا.
- `flutter build linux --release --no-pub`: نجح.

تظل النسخ التلقائية ملفات قاعدة بيانات فقط، ويظل قبول Windows والأجهزة الحقيقية مفتوحًا.
