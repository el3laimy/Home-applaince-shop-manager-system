# الدفعة 24: المساعدة والتشخيص واختبار الطابعة وصحة وجهة النسخ

التاريخ: 11 سبتمبر 2026.

## المنفذ

- تقرأ شاشة المساعدة إصدار التطبيق ورقم البناء من الحزمة الفعلية، وتعرض تاريخ آخر نسخة تلقائية بصياغة لا توحي بأنه يشمل الصور.
- يعاين المستخدم تقرير الدعم كاملًا قبل حفظه. التقرير منقح ولا يرسل شيئًا تلقائيًا، ويحتوي إصدار التطبيق ومخطط البيانات والنظام وحالة النسخ فقط.
- أضيفت صفحة اختبار طابعة عربية ثابتة على A4. قبول نظام التشغيل لطلب الطباعة لا يُعرض على أنه إثبات خروج الورق.
- تفحص حالة النسخ المجلد المختار حتى قبل حلول موعد النسخة التالية. اختفاء قرص أو مجلد بعد نجاح سابق ينتج تحذيرًا مع إبقاء تاريخ النجاح السابق، ثم يزول التحذير بعد عودة الوجهة.

## الأدلة

- `printer-test-page.pdf`: ملف PDF فعلي من مولد التطبيق، صفحة واحدة A4، 10,939 بايت.
- `printer-test-page.png`: تحويل بصري للصفحة؛ روجعت العربية والأرقام وحدود الصفحة بلا قص ظاهر.
- `analyze.log`: التحليل الساكن نظيف.
- `full-tests.log`: تحقق شامل قبل إضافة اختبار الطابعة الاختياري إلى شاشة الإعداد، ونجح فيه 142 اختبارًا.
- أعيد بعد إضافة خطوة الإعداد تشغيل مجموعة V2 كاملة تفاعليًا، ونجح **143 اختبارًا**، كما أعيد بناء Linux والحزمة أدناه.
- `linux-build.log`: بناء Linux Release ناجح من الكود النهائي.
- `alikhlas-pos_1.0.0_amd64.deb`: حزمة Debian x64 معاد بناؤها، حجمها 13,247,392 بايت وبصمتها SHA-256 هي `813adf5b4a75db502d6ee3ca5cf41f0a72c4b62da9f309a8fd8399e7f56007ac`.
