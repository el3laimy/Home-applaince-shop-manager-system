# دفعة 17: استعادة وصول المالك

- رمز استعادة عشوائي يظهر مرة عند إعداد المالك ولا يحفظ كنص؛ المخزن المحلي يحتوي تحقق PBKDF2 فقط.
- الاستعادة تغيّر كلمة المرور، تدور الرمز، وتوقف المحاولات بعد خمس أخطاء لمدة 15 دقيقة.
- المستخدم الذي يغيّر كلمة المرور الافتراضية يحصل أيضًا على رمز استعادة.
- اختبارات منطقية وواجهة تغطي التخزين غير النصي وتدوير الرمز والمهلة والاستعادة من شاشة الدخول.
- `dart analyze lib/v2 lib/main.dart test/v2`: بلا ملاحظات.
- `flutter test --no-pub`: 119 اختبارًا ناجحًا.
- `flutter build linux --release --no-pub`: نجح، وأعيد بناء وفحص حزمة Debian الناتجة.

رمز الاستعادة لا يشفّر قاعدة البيانات. يظل إجراء الدعم عند فقد كلمة المرور والرمز، واختبار الاسترجاع بعد نسخة قديمة، من أعمال ما قبل الإصدار النهائي.
