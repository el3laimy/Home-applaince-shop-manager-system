# الدفعة 28: جرد وتسوية مخزون موثقة

التاريخ: 11 سبتمبر 2026.

## المنفذ

- نافذة جرد من إجراءات كل صنف تقبل الكمية الفعلية بالأرقام العربية أو الإنجليزية، والسبب، والتوضيح.
- مراجعة ثانية تعرض الرصيد السابق والكمية المعدودة والفرق وتغير قيمة المخزون قبل الاعتماد.
- مستند تسوية دائم مع حركة مخزون وقيد متزن؛ لا تعديل صامت لرصيد المنتج.
- سياسة القيمة تستخدم متوسط التكلفة. عند غيابه يطلب التطبيق تكلفة الوحدة ويثبتها.
- حساب مستقل `inventory_variance`: النقص مدين والزيادة دائنة، ويظهر في ملخص اليوم والفترة ويؤثر في الربح.
- رفض لقطة جرد قديمة إذا تغير الرصيد أو متوسط التكلفة أثناء المراجعة.
- مفتاح عملية دائم وطلب معلق قابل للاستعادة؛ تكرار نفس الحمولة يعيد المستند، وتغييرها يرفض، وفشل الإيصال يرجع المعاملة كاملة.
- فحص الاتساق يتحقق من المستند والحركة والقيد، ويرتب سلسلة المخزون بالمعرّف التسلسلي حتى لا تؤدي ساعة جهاز رجعت للخلف إلى إنذار كاذب.
- مخطط Drift v6 ينشئ `inventory_adjustments` وفهرس الصنف والتاريخ؛ اختبرت الترقية من v3 وv4.
