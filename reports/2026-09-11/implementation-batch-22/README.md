# دفعة 22: مساعدة داخل التطبيق وتقرير دعم منقح

- يظهر زر «المساعدة» دائمًا في القائمة ويعرض خطوات عربية عند الشك في حفظ عملية أو فشل الطباعة، مع حالة النسخ الاحتياطي الحالية.
- يستطيع المستخدم اختيار مكان لحفظ تقرير دعم نصي. التقرير يحتوي على نسخة التطبيق ومخطط البيانات والنظام وحالة النسخ فقط، ولا يحتوي على قاعدة البيانات أو الفواتير أو العملاء أو الهواتف أو كلمات المرور أو مسارات الملفات.
- اختبار مستقل يثبت تنقيح مسار النسخ ومحتوى التحذير، واختبار واجهة يفتح شاشة المساعدة. روجعت لقطات Golden للقائمة وشاشة المساعدة بصريًا.
- `dart analyze lib/v2 lib/main.dart test/v2`: بلا ملاحظات.
- `flutter test --no-pub`: 122 اختبارًا ناجحًا.
- `flutter build linux --release --no-pub`: نجح، ثم أُنشئت وفُحصت حزمة `alikhlas-pos_1.0.0_amd64.deb`.

يلزم اختبار نافذة اختيار مكان الحفظ ومشاركة التقرير على Windows وLinux، ودليل مصور وجهة دعم وساعات استجابة معتمدة، قبل اعتبار بند الدعم مقبولًا ميدانيًا.
