# دفعة 20: استرجاع محل سابق في شاشة البداية

- خيار البداية يقبل ملف `.db` أو حزمة `.zip` لمحل قائم قبل إنشاء حساب جديد.
- يستخدم الاسترجاع فحص الملف ونسخة الرجوع الموجودة، ثم يعيد التطبيق إلى تسجيل الدخول لبيانات النسخة.
- `dart analyze lib/v2 lib/main.dart test/v2`: بلا ملاحظات.
- `flutter test --no-pub`: 119 اختبارًا ناجحًا، بما فيها صورة Golden المحدثة لشاشة البداية.
- `flutter build linux --release --no-pub`: نجح، ثم بُنيت وفُحصت حزمة Debian الناتجة.

يلزم اختبار منتقي ملفات النظام ووسيط النسخ والتشغيل على جهاز مستخدم حقيقي قبل اعتماد خطوة الإعداد ميدانيًا.
