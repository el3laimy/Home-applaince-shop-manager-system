# دفعة 19: اسم المحل ضمن الإعداد الأولي

- يطلب إعداد محل جديد اسم المحل مع اسم المالك وكلمة المرور.
- تحفظ البيانات ورمز الاستعادة معًا بعد التحقق؛ رفض اسم فارغ لا ينشئ حسابًا.
- اختبارات الإعداد والاستعادة والواجهة المركزة نجحت، والتحليل الساكن نظيف.

تظل استعادة نسخة سابقة واختيار النسخ والطابعة ضمن معالج أول تشغيل أعمالًا مفتوحة.
