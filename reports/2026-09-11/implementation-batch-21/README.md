# دفعة 21: وجهة النسخ في أول تشغيل

- يعرض إعداد محل جديد اختيار مجلد للنسخ الاحتياطي كخطوة اختيارية، مع رسالة واضحة عند التخطي.
- بعد إنشاء المالك، يحفظ التطبيق الوجهة المختارة ويحاول إنشاء أول نسخة تلقائية؛ يعرض للمستخدم النتيجة دون أن يحجب الدخول إذا فشلت النسخة.
- أصبح نموذج الإعداد قابلًا للتمرير على الشاشات الأقصر، وصورة Golden المحدثة روجعت واعتمدت.
- `dart analyze lib/v2 lib/main.dart test/v2`: بلا ملاحظات.
- اختبارات الإعداد والنسخ: 21 ناجحة، و`flutter test --no-pub`: 119 اختبارًا ناجحًا.
- `flutter build linux --release --no-pub`: نجح، ثم أُنشئت وفُحصت حزمة `alikhlas-pos_1.0.0_amd64.deb`.

يلزم اختبار منتقي مجلدات النظام ووسيط نسخ حقيقي وصلاحيات الوصول على Windows وLinux، إضافة إلى التثبيت والترقية والإزالة على أنظمة نظيفة، قبل اعتماد التجربة للمستخدم النهائي.
