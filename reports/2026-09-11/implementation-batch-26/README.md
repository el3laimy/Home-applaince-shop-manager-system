# الدفعة 26: اختبار الطابعة في الإعداد الأول

التاريخ: 11 سبتمبر 2026.

## المنفذ

- يستطيع صاحب المحل اختبار صفحة عربية A4 من شاشة الإعداد قبل إنشاء حساب المالك.
- اسم المحل مطلوب قبل الاختبار كي تظهر الصفحة بالاسم الصحيح.
- الخطوة اختيارية بوضوح؛ يمكن بدء العمل وضبط الطابعة لاحقًا من شاشة المساعدة.
- رسائل النتيجة تفرق بين إلغاء حوار الطباعة، قبول الطلب من النظام، وفشل فتح الطباعة. قبول الطلب يطلب من المستخدم فحص الورق والعربية، ولا يدعي نجاح الطابعة.
- أثناء الاختبار تتعطل أزرار الإنشاء والاسترجاع واختيار النسخ حتى لا تتداخل عمليات الإعداد.

## التحقق

- اختبار واجهة يثبت رفض الاختبار قبل اسم المحل، وتمرير الاسم بعد تنظيف المسافات، وبقاء إنشاء المالك اختياريًا ومستقلًا عن إلغاء الطباعة.
- اختبار إنشاء محل من دون طابعة بقي ناجحًا، لذلك لا تحجب الخطوة المستخدم.
- روجعت لقطة شاشة الإعداد عند 1280x800: كل الحقول والنسخ والطابعة وزر البدء ظاهرة بلا قص.
- التحليل الساكن نظيف، ومجموعة V2 النهائية اجتازت **143 اختبارًا**. نجح بناء Linux Release، وأعيد إنشاء حزمة Debian الموجودة في الدفعة 24.

## حدود القبول

لا يخزن التطبيق طابعة مفضلة؛ الاختيار يتم في حوار النظام عند كل طباعة. لا يوجد بعد إثبات طابعة إيصالات أو باركود فعلية أو Windows، لذلك تبقى المعايرة والعتاد وقبول المستخدم النهائي مفتوحة.
